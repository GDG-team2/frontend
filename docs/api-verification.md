- 합성 계정 1개로 가입 → 로그인 → 토큰 재발급 → 프로필/설정/추천 기본값 저장 → 추천 → 출발 약속 → 다른 추천 중단 → 약속한 미션 출발 → 두 번의 도착 인증 → 설문/50P 지급 → 기록/상세/지도/포인트/배지/랭킹을 확인했습니다.
- 첫 도착 요청은 IN_PROGRESS와 체류 시간을 반환했고, 실제 30초를 기다린 두 번째 요청에서 ARRIVED를 확인했습니다. 조용한 시간 HH:mm 요청이 HH:mm:ss로 반환되는 것도 확인했습니다.
- 실제 사용자 계정이나 기기 위치는 사용하지 않았습니다. 공개 명세의 좌표와 추천된 장소 좌표를 쓰는 기능 테스트입니다. 합성 계정은 공개 랭킹에 참여하지 않습니다. 삭제 API가 없어 테스트 계정·기록은 개발 서버에 남습니다.

## 출시 전에 필요한 항목

- **약관 원문 URL 3개가 없습니다. 실제 회원가입은 비활성화한 상태입니다.** 약관을 준비하고 `.env.example`의 URL을 설정해야 합니다. 법률 문서를 임의로 만들지 않았습니다.
- 기본 주소는 초기화 가능한 개발 서버입니다. 운영 서버 설정이 필요합니다.
- 지역 선택/이름 조회 API가 없어 10자리 동네 코드를 직접 입력합니다. 현재 서버는 지역 이름을 `지역 정보 없음`으로 반환할 수 있습니다.
- 실기기 위치 권한·GPS 정확도·배터리/백그라운드 복귀·실제 이동은 검증하지 않았습니다. MSW와 합성 좌표를 통한 기능 검증만 수행했습니다.
- 푸시 실제 발송, 소셜 로그인, 인사이트, 쿠폰/제휴, 신고, 계정/데이터 삭제 및 내보내기 API는 제공되지 않았습니다. 지원되지 않는 기능은 준비 중으로 안내합니다.
- 내장 지도 SDK·실제 이동 거리/걸음 수 추적은 없으며 외부 카카오맵과 서버의 예상 거리·시간을 사용합니다.

따라서 연동과 주요 흐름 검증은 완료했지만, 위 조건을 해결하기 전에는 일반 사용자 대상 운영 출시 완료로 보지 않습니다.
