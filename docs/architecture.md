# 백엔드 연동 (2026-10-01)

`api.json`은 배포된 서버의 `/v3/api-docs`와 paths/schemas가 일치하는 23개 연산 명세입니다. 출처는 [변경 안내](https://claude.ai/artifact/Y5dBA7crDZqieuP5GQGe9G)와 [백엔드 명세](https://github.com/GDG-team2/backend1/blob/732ea413524b7cc9dbc326fe520d0ea9dfbc7fd1/docs/openapi.json)입니다. `bun run api:types`로 enum을 포함한 DTO를 재생성합니다. 응답에 required/nullable 표기가 부족하므로 어댑터는 핵심 식별자·좌표·상태를 확인하고 선택값을 방어적으로 표시합니다.

## 연결과 세션

기본 API는 `https://ohakkom-backend.onrender.com/api/v1`, 요청 제한은 90초입니다. 네트워크 실패나 서버 오류에 읽기만 1회 재시도하며, 일반 변경 요청은 자동 재시도하지 않습니다. 읽기와 쓰기 모두 networkMode=always를 사용해 오프라인에서 무기한 대기하거나 재연결 때 변경 요청을 뒤늦게 실행하지 않고 오류를 표시합니다. 서버의 code/message/details를 보존하고 입력 오류 세부 메시지를 표시합니다. GPS 조회는 20초 후 명시적 재시도를 안내합니다.

로그인 응답의 액세스·리프레시 토큰을 한 레코드로 저장합니다. 네이티브는 SecureStore, 웹은 AsyncStorage이며 모드·API 주소별로 키를 분리합니다. 구버전 액세스 토큰만 있는 세션은 다시 로그인해야 합니다. 비밀번호는 저장하지 않습니다. 웹에서는 동일 출처 스크립트가 저장소를 읽을 수 있으므로 호스팅에 적절한 CSP/XSS 방어가 필요합니다.

401 TOKEN_EXPIRED는 동시 요청에서도 재발급 1회를 공유하고 새 토큰 쌍을 원자적으로 교체한 뒤 각 요청을 1회만 재전송합니다. 재발급의 네트워크/5xx 실패는 세션을 보존합니다. 인증 불가 시 토큰과 쿼리 캐시를 비웁니다. 로그아웃 또는 다른 계정 로그인 뒤 도착한 이전 재발급/401은 새 세션을 지우거나 복원하지 못하도록 저장소 연산을 직렬화합니다. 세션 세대 번호를 비교해 계정 변경 전에 시작한 응답을 버리고, 새 계정으로 재전송하지 않습니다. 로그인 상태가 바뀔 때 QueryClient를 교체해 이전 변경 요청의 완료 콜백도 새 캐시를 건드리지 못하게 합니다. Stack.Protected가 비로그인 상태의 보호 화면 마운트를 막습니다.

MSW는 명시적인 `EXPO_PUBLIC_USE_MSW=true`에서만 시작합니다. QA 헤더·모의 좌표·QA 진입도 같은 조건입니다. 실제 서버 실패를 목업 성공으로 바꾸지 않습니다.

## 미션과 시간

현재 상태는 GET current로 읽고 추천은 사용자 행동에만 POST합니다. 추천 조건과 거절 이유는 enum 값으로 전달합니다. 화면에 표시된 미션이 서버의 현재 미션과 달라지면 쓰기를 멈추고 재조회합니다.

READY → 선택적 schedule → start → IN_PROGRESS → arrive(체류 시작) → 30초 후 새 좌표로 arrive → ARRIVED → complete 순서입니다. 첫 arrive 성공을 완료로 오인하지 않습니다. 반경 밖이면 서버가 체류를 초기화하고 UI도 대기를 지웁니다. 버튼의 카운트다운은 재요청 안내이며 실제 인증은 서버만 결정합니다. 앱 재진입 뒤에도 다시 arrive하면 서버가 남은 체류 시간을 반환합니다.

여러 예정 미션은 개별 ID로 출발/시간 변경/취소합니다. 약속 취소는 화면에서 한 번 더 확인하고 abort합니다. 중도 종료는 이유를 전송하고 다음 추천 안내를 표시합니다. stepCount/movedDistanceMeters는 실제로 측정하지 않으므로 임의 값을 보내지 않습니다. 완료 응답의 포인트·주간 리듬·랭킹·배지를 반영하고 관련 조회를 무효화합니다. 완료 응답 유실 후에는 재제출보다 포인트·기록 확인을 안내합니다.

시간대 없는 서버 시각은 항상 한국 시간(+09:00)으로 파싱합니다. 약속도 한국 시간 문자열로 보냅니다. 현재 미션 API에 없는 예상 시간/거리 등은 추천 직후 메모리에 보존하며 재시작 후에는 미제공 값을 `—`로 표시합니다.

## 설정·기록·프로필

설정과 추천 기본값은 GET으로 조회하고 바꾼 필드만 PATCH합니다. 조용한 시간은 HH:mm 문자열로 전송하고 HH:mm:ss 응답을 표시합니다. 프로필 편집 후 홈·랭킹 캐시를 갱신합니다. 기록은 주간/월간/전체, 활동/무료 필터와 페이지 이동을 지원하고 상세의 기분 변화·타임라인을 표시합니다. 지도 목록은 서버의 방문 장소·통계·최근 기록을 사용하며 카카오맵 링크로 위치를 엽니다.

주간 리듬은 N회 목표와 연속 달성 주 수를 표시합니다. 랭킹의 주 3회 반영·100점·범주 보너스 20점 규칙을 안내하고 서버 점수를 그대로 표시합니다. 배지 진행도와 포인트 페이지도 서버 응답을 사용합니다.

약관 URL이 미설정된 실제 가입은 비활성화합니다. 동의는 기본 미선택입니다. 없는 약관 본문을 만들거나 미동의를 true로 보내지 않습니다. 미지원 범위와 운영 배포 조건은 README에 명시했습니다.
